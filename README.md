## 📦 Скачивание отдельных папок

Для скачивания одной папки из репозитория можно использовать расширение **GitZip** (Chrome/Firefox).

⚠️ **Внимание:** GitZip может нарушать структуру C# проектов — отсутствие `.sln` и `.csproj` в корне скачанной папки приводит к ошибкам сборки. Рекомендуется клонировать весь репозиторий через `git clone`.
