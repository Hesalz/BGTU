## 📦 Скачивание отдельных папок

Для скачивания одной папки из репозитория можно использовать расширение **GitZip** (Chrome/Firefox):
🔗 **URL:** https://chromewebstore.google.com/detail/gitzip-for-github/ffabmkklhbepgcgfonabamgnfafbdlkn?hl=tg

⚠️ **Внимание:** GitZip может ломать относительные пути, повреждать структуру многопроектных решений, вырывать файлы из контекста и нарушать связи между проектами. В результате код может не собраться или работать некорректно.
✅ **Рекомендация:** лучше использовать `git clone` для клонирования лабораторных работ на C#, C++ и в многопроектных решениях.
