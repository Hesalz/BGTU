# DCT Steganography

Курсовой проект: приложение для скрытия текстовых сообщений в цифровых изображениях методом блочного DCT.

## Возможности

- скрытие текстового сообщения в изображении;
- извлечение сообщения по паролю;
- шифрование сообщения перед встраиванием;
- PBKDF2-HMAC-SHA256 + Fernet;
- случайная соль для каждого сообщения;
- контроль целостности SHA-256;
- настройка силы встраивания `2–5`;
- автоматическая проверка результата после встраивания;
- расчёт MSE и PSNR;
- benchmark по значениям strength `1–5`;
- SQLite-история операций;
- графический интерфейс на PySide6;
- поддержка цветных изображений с встраиванием в канал яркости Y пространства YCrCb;
- сохранение исходной цветовой информации при формировании stego-изображения.

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

## Benchmark

```bash
python run_benchmark.py --image path/to/image.png
```

Benchmark выводит для каждого уровня strength:
- успешность контрольного извлечения;
- PSNR;
- MSE;
- время внедрения;
- время извлечения.

Для текущей реализации значение `strength=3` используется как стандартное в графическом интерфейсе.
