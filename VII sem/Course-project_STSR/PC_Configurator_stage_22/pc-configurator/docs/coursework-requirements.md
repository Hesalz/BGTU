# Требования листа задания

- Регистрация и авторизация.
- Роли: пользователь и администратор.
- Создание и редактирование конфигураций ПК.
- Проверка совместимости и объяснение несовместимостей.
- Отображение характеристик, итоговой стоимости и энергопотребления.
- Сохранение, просмотр и сравнение конфигураций.
- Администрирование каталога и справочных данных.
- Асинхронный UI и независимость представления, бизнес-логики и хранения данных.
- Docker-развёртывание.
- UML Use Case, логическая схема БД и структурная схема приложения.
- TypeScript, Node.js, React.
