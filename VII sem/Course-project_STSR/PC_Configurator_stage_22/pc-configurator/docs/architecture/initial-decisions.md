# Начальные архитектурные решения

## ADR-001. Модульный монолит
Для курсового проекта используется модульный монолит NestJS. Модули разделяются по предметным областям. Микросервисы на старте не применяются.

## ADR-002. Microsoft SQL Server
Основная СУБД — Microsoft SQL Server 2022 Developer в Docker. Доступ к данным через TypeORM и драйвер `mssql`.

## ADR-003. REST API
HTTP API версионируется префиксом `/api/v1`. Клиент не имеет прямого доступа к базе данных.

## ADR-004. Слои ответственности
Контроллеры отвечают за HTTP; сервисы — за прикладные сценарии; репозитории — за персистентность. Проверка совместимости будет отдельным модулем бизнес-логики.

## ADR-005. Временная стратегия схемы БД
Для раннего прототипирования `synchronize` включается через `DB_SYNCHRONIZE=true`. До появления важных/пользовательских данных необходимо перейти на миграции TypeORM и отключить автоматическую синхронизацию схемы.
