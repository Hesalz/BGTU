# 1. 15 тестов.

| № | Проверка | Что подтверждается |
|---:|---|---|
| 1 | Формирование и разбор payload без пароля | Исходный текст восстанавливается без изменений |
| 2 | Формирование и разбор зашифрованного payload | Текст восстанавливается с правильным паролем |
| 3 | Разбор зашифрованного payload без пароля | Возникает ожидаемый `ValueError` |
| 4 | Повреждение данных payload | Проверка целостности обнаруживает изменение данных |
| 5 | Преобразование битов в байты при неполной группе | Возникает ожидаемый `ValueError` |
| 6 | Определение максимального размера сообщения | Найденная ёмкость позволяет разместить сообщение, но не следующее по размеру |
| 7 | MSE для одинаковых изображений | Ошибка равна нулю |
| 8 | MSE для различающихся изображений | Среднеквадратичная ошибка вычисляется правильно |
| 9 | Изображения разных размеров при расчёте метрик | Возникает ожидаемый `ValueError` |
| 10 | PSNR для одинаковых изображений | Возвращается бесконечное значение |
| 11 | Добавление и чтение истории | Запись сохраняется и возвращается с корректными полями |
| 12 | Встраивание с нулевой силой | Возникает `ValueError`, загрузчик изображения не вызывается |
| 13 | Сообщение превышает ёмкость изображения | Возникает `ValueError`, сохранение изображения не вызывается |
| 14 | Извлечение отрицательного количества битов | Возникает ожидаемый `ValueError` |
| 15 | Извлечение количества битов больше ёмкости | Возникает ожидаемый `ValueError` |

## 2. Запуск тестов

Из корневого каталога проекта выполнить:

```bash
python -m pip install pytest pytest-cov
python -m pytest -v --cov=app --cov-report=term-missing
```
