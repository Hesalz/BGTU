## Информация
# lab06_1 - Задание 1 на сайте demoqa.com
Находит элементы разными способами:
-	By.id / By.name
-	по CSS-селекторам (2 разных примера составных селекторов) 
-	по XPath (2 разных примера составных XPath) – имеются в виду составные пути, а не просто div
-	по частичному тексту ссылки 
-	найти несколько элементов, которые возвращаются в виде списка или массива 

# lab06_2 - Задание 2 на сайте demoqa.com
Выполняет 5 тестов:
- test_login_to_demoqa_profile / Проверка формы авторизации: неверные данные должны дать сообщение об ошибке.
- test_text_box_form_submission / Заполнение формы Text Box и проверка результата.
- test_web_tables_add_record / Добавление записи в Web Tables и проверка таблицы.
- test_end_to_end_book_collection / Сквозной сценарий: вход под существующей учетной записью, добавление книги, проверка и удаление.
- test_select_dropdown_and_checkbox / Проверяет выбор значения в выпадающем списке и checkbox на форме.

# lab06_X - Задание 2 на сайте Realt.by (из 5-ой лабораторной)
Выполняет 5 тестов:
- test_authorization_form_opens / Проверка открытия формы авторизации.
- test_tc01_filter_apartments_by_two_rooms / Проверка фильтрации квартир по количеству комнат: две комнаты, наличие соответствующего заголовка и объявлений в выдаче.
- test_tc02_open_listing_from_map / Проверка открытия конкретного объявления через режим карты.
- test_end_to_end_search_and_open_apartment / Сквозной сценарий: поиск двухкомнатных квартир и открытие объявления.
- test_room_filter_control_can_be_selected / Проверка взаимодействия с фильтром количества комнат и выбора варианта для двух комнат.
